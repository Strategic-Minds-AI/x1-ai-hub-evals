# VERIFIED_100 Contract

VERIFIED_100 is certification, not release permission.

Requirements:
- all applicable HARD gates PASS;
- build/lint/type/unit/integration/API/security/data/queue/runtime checks pass where applicable;
- tenant isolation and RLS tests pass;
- protocol/MCP conformance passes;
- 100% declared visible control/action coverage for the selected UI scope;
- required responsive/accessibility/console/network/browser checks pass;
- zero mandatory UNKNOWN/FAIL/BLOCKED;
- zero open P0/P1;
- source/deployment parity tied to immutable SHA/runtime identity;
- protected-action policy compliance;
- three fresh non-replayed clean cycles against the same immutable SHA/runtime identity.

Any material upstream change invalidates impacted evidence.
